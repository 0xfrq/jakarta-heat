# NV-02 evidence boundary

All candidate results describe five mainland Jakarta cities with 2024 raster/demographic patterns and an OSM 19 November 2026 candidate-park network proxy. Kepulauan Seribu is outside scope. Surface temperature is not air temperature or personal exposure. A model ranking is not a verified location for an intervention.

`benchmark_comparison.csv` compares M4 to heat-only and equal-weight planning rules on the identical supported **2,536-grid** common comparison set. Spatial statistics use the same common set minus the single Queen island (`JKT_R013_C019`), i.e. **2,535 tested observations** where applicable. Both share model inputs and are **internal transparent benchmarks**, not independent outcomes. The equal-weight rule uses L, low NDVI, age count and distance deficit equally. `geographic_cases.csv` selects, by a deterministic rule, the four largest M3→M4 rank gains and the four largest rank losses (`rank_gain` = M3 rank − M4 rank; ties broken by grid ID; column `case_selection`). The earlier largest-absolute rule returned only losses because the shift distribution is asymmetric (min −1061, max +472) and joins grid ID, city, measurements, support, snap and rank attribution. Map annotations name actual grid IDs and cities only; no unsupported neighborhood name or park-opening claim is invented. Full-area M1–M3 and excluded cells are exported separately.

Independent heat-health outcomes, air sensors, cooling effectiveness and intervention outcomes are not available in the frozen workstream. Satellite-derived surrogates from the same input are not treated as independent validation. AC-01/02 dated operator/entrance/connector evidence and revised per-grid routes are pending Agent 2; the absence is material for claims about actual usable public parks. No predictive accuracy, mortality reduction, superior policy outcomes or causal mechanism is claimed. A qualified decision-sensitivity contribution can be assessed without these stronger claims, subject to coordinator approval and independent re-audit.

Figures are listed in `outputs/remediation/paper/figure_manifest.csv` with repository-relative paths, the figure SHA-256, every real source file used (`source_files`, `;`-separated: candidate tables plus grid/boundary geometry) and each source file's SHA-256 (`source_sha256`); a regression test re-hashes them. Every table/mapped membership is keyed by `grid_id`; missing or excluded cells retain a distinct legend state. Scientific outputs and source files have separate manifests.
