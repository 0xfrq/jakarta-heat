# Explicit spatial inference specification — ST-01

Implementation tested with esda **2.10.0**, libpysal **4.15.1** (see `requirements-agent3.lock`, a local environment snapshot, not an integrated project lock). Queen polygon contiguity via intersections, row-standardized; Rook and centroid KNN8 are global sensitivities. Islands are removed iteratively and exact IDs and directed neighbor weights are exported. The audited 2538-grid universe had 2537 Queen observations after excluding JKT_R013_C019; source-support correction removes that grid, so the 2526-grid candidate has 2526 observations and no islands. These are different universes.

Global null: spatial randomization of values; alternative: **positive autocorrelation**. `p_sim=(1+sum(I_perm>=I_observed))/(R+1)` is explicitly upper-tail; the normal-theory two_tailed parameter does not define permutation tails. Global permutations are unconditional label shuffles, not local conditional permutations. Global p_norm is reported separately with its directed normal convention.

Local: esda conditional randomization, seed 42, `alternative="directed"` explicitly preserves the audited convention. `alternative="two-sided"` is a separate sensitivity passed directly to esda, not inferred from a default or manufactured by relabeling. Current baseline R=999; resolution is 1/(999+1)=.001. Sensitivities run R=9999 with .0001 resolution, both alternatives, for M4. Exact per-grid I, p, alternatives, seed, permutation count and label changes are stored. No p=0 interpretation is valid.

Proposed testing family: all non-island eligible grids **within each preselected map separately** (M1–M4). It is not a family across all interactive selections. BH at q=.05 is explicit step-up correction; standard FDR interpretation requires independence or suitable positive dependence. Spatial dependence does not automatically establish that condition. BY uses q/H_m and controls more conservatively under arbitrary dependence; it is exported as sensitivity. No significant local label is independent evidence of index validity or health/policy benefit. Maps may differ materially under tail, correction and permutation resolution; exact IDs rather than counts alone are exported in `lisa_tail_permutation_grid.csv`.

Coordinator must approve the substantive tail and family before local-significance claims are finalized. Until then directed output is a documented provisional comparator and two-sided/BY alternatives must accompany substantive cluster interpretations. More permutations do not resolve construct validity or multiplicity-family choice.
